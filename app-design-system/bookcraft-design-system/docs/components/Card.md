Bordered `surface` panel with an optional header row (icon, title, meta, actions).

**Props:** `title`, `icon`, `meta` (node after the title, usually a Badge), `actions` (right-aligned buttons), `flush` (no body padding — for tables), `children`.

- Cards sit on `bg` with a 1px `border` and `radius-lg`; no drop shadows.
- Header icon is `accent-text`. Keep one primary action per card.
