Labelled input, textarea, select or search box.

**Props:** `as` text (default) | textarea | select | search; `label` (rendered as uppercase `label` style), `hint`, `options` (select), `rows`, `value`/`defaultValue`, `onChange`, `placeholder`.

- Controls sit on `surface-raised` with a `border-strong` outline (≥3:1) and a 2px `accent-text` focus ring.
- Labels are nouns (“Target audience”), placeholders are examples, never instructions.
