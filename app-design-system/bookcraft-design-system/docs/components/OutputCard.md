A generated text asset with title, tag, live word count and a one-click copy button.

**Props:** `title`, `text`, `icon`, `tag`, `tagTone`, `limit` (shows a char count against the channel limit).

- Use for personas, social posts and blurbs in Phase 1. The copy button confirms with “Copied” in `success-text` for 1.4s.
- Show the channel as the tag (`Instagram`, `amazon-kdp`) so counts make sense.
